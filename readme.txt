Instalación y ejecución del proyecto Tiendamia

Clonar o descargar el proyecto.
Crear un entorno virtual con python -m venv venv.
Activar el entorno virtual.
Instalar las dependencias con pip install -r requirements.txt.
Verificar que en settings.py estén registradas las apps necesarias (rest_framework, corsheaders, drf_spectacular, core).
Aplicar las migraciones con python manage.py migrate.
Ejecutar el servidor con python manage.py runserver.
Acceder desde el navegador a http://127.0.0.1:8000/
